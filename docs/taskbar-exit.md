# 正常退出时恢复 Windows 任务栏（本地 V11）

旧版将系统任务栏窗口隐藏后，退出只注销 Dock/顶部状态栏的 AppBar、恢复部分状态位，没有重新显示任务栏窗口，因此 MiniDock 已退出后仍看不到任务栏。V9/V10 的顶部自动隐藏状态恢复也只覆盖特定顶部配置，不能代替显示窗口。

V11 在控制任务栏时记录最后写入的自动隐藏/置顶状态以及是否操作过窗口。正常退出先释放自身占位和工作区覆盖，再恢复原生任务栏：当系统状态仍等于本程序最后写入值时，恢复启动时保存的原状态（包括合法的 0 值）；如外部后来改变了状态则保留。随后显示主任务栏及全部副屏任务栏，不改变其位置、大小或输入焦点，通知 Explorer 重新计算最终工作区。

MiniDock 的隐藏配置仍保留，下次运行可以继续隐藏任务栏；不是把 INI 中的 TaskHide 永久改成 0。设置界面补充说明：隐藏仅在 MiniDock 运行时生效，正常退出后恢复 Windows 任务栏。原有透明度功能不在本轮修复范围。

对已经退出旧版、任务栏仍不可见的情况，另外提供本地恢复工具：双击 RestoreTaskbar.exe 会关闭 Windows 任务栏自动隐藏并显示主/副屏任务栏，保留位置，不改 MiniDock 配置，工具随后结束。此应急工具未自动运行，也不编入 MiniDock 主 EXE。它与正常退出恢复原自动隐藏偏好的路径不同。

强制结束进程或崩溃可能不执行 WM_DESTROY，不能依赖正常退出清理；若 MiniDock 已完全停止，可使用恢复工具。仍有 MiniDock 进程运行时，其原有隐藏定时器可能再次隐藏任务栏。

新增 17 项私有窗口/Shell 替身检查，覆盖原状态 0、原自动隐藏偏好、多副屏、未知原状态、后续外部变更、重复清理、主任务栏消失、未控制时不干预、生产隐藏路径跟踪及枚举窗口失效。不会在测试中操作用户实际任务栏。与既有 254 项检查合计 **271 项通过**，完整构建通过。

同 GCC 16.2.0、原资源与构建参数，V10 为 437,760 字节，V11 为 **438,272 字节**（+512 字节）。相对当前 main 的 432,640 字节增加 5,632 字节（5.5 KiB，约 1.30%）。系统 DLL 仍为 20 个，`.bss` 为 0x1638c0，新增的状态记录只占少量固定数据。没有新增常驻线程或周期定时器；枚举与显示操作只在退出清理时进行，未重新测量长期整进程 CPU/内存。
