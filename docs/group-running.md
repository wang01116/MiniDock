# 分组中的运行应用显示在右侧

在“设置 → 通用”开启“显示未固定的运行中应用”，再开启“分组中的运行应用也在右侧显示”。

新选项默认关闭，旧配置保留原显示方式。开启后，组内应用的已有窗口会在右侧运行区显示独立图标，原应用组和组内快捷方式继续保留。直接固定在 Dock 主栏的应用不会重复显示；被选入托盘名单的应用继续使用最右侧的专用图标，文档窗口继续遵循原多窗口显示方式。运行区仍按现有可显示应用窗口扫描，隐藏到托盘的应用由原托盘名单管理。

普通点击运行图标直接操作窗口句柄：最小化时恢复、位于后台时置前、位于前台时再次点击最小化（遵循原点击切换开关）。多窗口时当前前台窗口优先；其他情况下保留已绑定窗口，避免最小化后被另一个窗口替换。失效窗口可重新匹配同一 EXE 的已有窗口，普通点击不会回退到执行 EXE。所有窗口退出后图标随扫描移除，原固定快捷方式保留。显式 Shift 点击或新实例菜单仍可请求新实例。

组内快捷方式的“打开”也优先激活已有窗口；仅没有匹配窗口时才启动应用。普通固定图标不再仅凭过期的运行标志决定是否重新启动。

配置项为 `[Settings] ShowGroupRunning=0/1`，与现有 `ShowRunning=1` 配合使用。设置导出、导入、保存和重载沿用现有配置表。修改相关开关时复用现有扫描立即刷新。

本改动沿用程序现有权限。管理员权限窗口仍需要相应权限才能可靠控制；本改动没有变更 Windows 自启任务。资源对比和测试见 [tests/README.md](../tests/README.md)。
