为什么这么轻

把资源还给系统，把控制交给用户

桌面美化工具通常会引入 WebView、托管运行时或一整条 GPU 特效管线，代价是几百 MB 内存和肉眼可见的延迟。MiniDock 走另一条路：全部用系统原生 API 手写绘制，只实现真正会用到的功能，并且每一项都能单独关掉。

空闲时几乎不耗电

没有常驻的动画定时器：不悬停、不动画时只做必要的消息循环。磨砂、预览、倒影等开销较大的效果默认按需开启。

细到每一项都能关

磨砂玻璃、窗口预览、最小化动画、图标倒影、状态栏、资源监视器……设置里都有独立开关，配置可整体导入导出。

单文件，解压即用

不写系统目录、不装服务、不留常驻后台程序。配置放在 %APPDATA%\MiniDock，删掉程序文件即可卸载。

换显示器不漂移

Per-Monitor V2 DPI 感知。从 3:2 笔记本切到 16:9 外接屏，Dock 尺寸和悬停缩放保持稳定，不会忽大忽小。

可选日志，默认关闭

遇到问题时可一键开启日志收集：只记录生命周期、显示器与错误码等事件，不记录窗口标题、文件路径、输入内容、剪贴板和截图，总量限制在约 2 MiB。

不是全家桶

没有天气、没有联网资讯、没有系统优化器。MiniDock 只做 Dock 与状态栏，把决定权留给用户。

Dock 能力

macOS 的手感，Windows 的原生

该有的都有，不该有的不堆。

应用固定与合并/独立显示

拖入应用、文件夹、网址即可固定，也能从开始菜单直接拖拽。窗口可按应用合并，或像 macOS 一样每个文档、每个资源管理器窗口单独占一个图标。

应用组

把图标拖到一起即可成组：宫格卡片、可命名、可换图标、可调背景色与不透明度、可拖拽排序，末尾的「＋」随时补充。

弧形堆叠展开

点击文件夹以弧形列出内部文件，弧度可调（0 为垂直）；支持拖出、右键与排序，贴近 macOS 的视觉习惯。

窗口预览

悬停运行中的应用时显示实时缩略图（系统 DWM 缩略图，仅在悬停时占用资源），多窗口自动排列，点击直达对应窗口。

起动台

全屏网格列出开始菜单应用，打字即搜、回车启动、Esc 关闭；图标懒加载，背景不透明度可调，右键空白处直达起动台设置。

速记与临时周转组

速记点击即记，支持加粗、倾斜、项目符号，可导出 txt / Markdown；临时组用来周转本次工作的文件，重启后自动清空。

外观全可调

纯色 / 多色渐变 / 真磨砂玻璃三种底盘，跟随系统强调色；深色图标可批量调整，图标倒影、圆角、边框、分割线均可微调。

运行指示

已打开的应用显示横条或圆点，颜色、样式、大小可自定义；配合窗口预览，一眼看清哪些程序正在运行。

任务栏控制

可隐藏系统任务栏或交给自动隐藏；设为永久隐藏时，Ctrl 悬停屏幕边缘可临时唤出。关闭控制后恢复系统原始设置，Explorer 重启也会重新应用。

通知提醒

接管应用的任务栏闪烁与未读红点，点击直达对应窗口。系统自带的 Toast 内容第三方读不到，所以不做假数据。

专注模式

一键切换「工作 / 开发 / 娱乐」等多套 Dock 布局与配色，每套配置独立保存。

资源监视器

CPU / 内存 / 磁盘占用实时采样，点击展开详情；只在你开启时才采样，关闭后不再唤醒。

游戏模式

游戏运行时鼠标滑到屏幕边缘不会弹 Dock（防误触），顶部状态栏也会一并隐藏，退出游戏后自动恢复。

Dock 在左 / 右 / 下

停靠在左右两侧时，已启用的小组件会收拢成一个 1×1 入口，点开是快捷列表，不再挡住桌面内容。

常见问题

你可能想问的

需要安装 .NET 或 VC++ 运行库吗？

不需要。MiniDock 是纯 Win32 + GDI+ 程序，静态链接了 gcc 运行时，只依赖 Windows 自带的系统 DLL。把 exe 放到任意目录双击即可运行。

为什么它这么小还有状态栏？

没有浏览器内核、没有托管运行时、没有 GPU 特效管线：界面全部用 GDI+ 逐像素绘制，图标、圆角、磨砂都是自己算的。功能按需加载，用不到的代码在链接阶段就被裁掉了。

会影响游戏或全屏程序吗？

可以把影响降到很低：游戏模式运行时会屏蔽边缘弹出（防误触）并隐藏状态栏；性能页还有「低资源」档，一次性关掉磨砂、窗口预览、最小化动画等。空闲时没有常驻动画定时器。

为什么通知小组件读不到系统通知内容？

Windows 不向第三方程序开放 Toast 通知的内容。MiniDock 接管的是「应用请求你注意」的信号——任务栏闪烁与未读红点，点击即跳到对应窗口，不会编造不存在的通知内容。

配置存在哪里？怎么备份到另一台电脑？

默认在 %APPDATA%\MiniDock，位置可在设置里改。换机时用「配置与备份」导出，再在新机器导入即可，图标、分组、布局、专注模式配置都会一并带走。

它会上传或收集我的数据吗？

不会主动上传任何内容。日志是可选功能，默认关闭；开启后只写本地文件，记录的是运行事件、显示器与错误码，不包含窗口标题、文件路径、输入内容、剪贴板和截图，文件上限约 2 MiB，可随时清空。联网只发生在你主动点「检查更新」时。

支持 Windows 7 吗？

目标平台是 Windows 10 / 11 64 位。程序链接 UCRT，Windows 7 需要额外安装 KB2999226 才可能运行，且未做验证，不推荐。

杀毒软件报毒怎么办？

exe 未做数字签名，加上它会操作窗口与任务栏，容易被启发式规则误判。可以：把文件加入信任、核对 Releases 页面的校验信息，或直接按下面的命令自己编译——源码是公开的。

开源与构建

用 MinGW-w64 自己编一个

全部逻辑集中在 minidock.c 一个文件里，资源在 res/。64 位 MinGW-w64 环境执行下面的命令即可生成 MiniDock.exe（约 400 KB）。

# 1) 编译资源（图标 / 清单 / 版本信息）
windres -O coff res/app.rc -o app_res.o -Ires

# 2) 编译并静态链接（1.7.x 起 SetSuspendState 需要 -lpowrprof）
gcc -Os -fno-ident -mwindows -s -static-libgcc ^
  -Wl,--gc-sections,--file-alignment=512 ^
  -o MiniDock.exe minidock.c app_res.o ^
  -lgdiplus -lole32 -loleaut32 -lshell32 -lshlwapi -luser32 -lgdi32 ^
  -lcomctl32 -lcomdlg32 -luuid -lurlmon -lversion -ldwmapi -ladvapi32 ^
  -lpsapi -luxtheme -liphlpapi -limm32 -lwtsapi32 -lpowrprof
