关于 MiniDock

把资源还给系统，把控制交给用户

很多 Dock 工具为了视觉特效引入了浏览器内核或重量级框架，代价是几百 MB 内存和肉眼可见的延迟。MiniDock 走的是另一条路：不追求面面俱到，只把 Dock 栏做好——更轻、更快、更自由。

轻到几乎感觉不到

纯 Win32 + GDI+ 绘制，没有 Electron / WebView。空闲时不跑动画定时器，内存自动回收，日常几乎不占 CPU。

细到每个像素都能调

图标底盘、分割线、运行指示、渐变、磨砂、弧形弧度、动画风格……都能单独设置，并可导入导出整套配置。

该有的都有

应用组、临时周转组、弧形堆叠、速记、时间日期、起动台、多显示器适配，聚焦 Dock 本身，不堆砌无关模块。

单文件，解压即用

不写系统目录、不装服务、不留后台驻留程序。想用就双击，不想用直接删掉文件夹。

换显示器不漂移

Per-Monitor V2 DPI 感知。从 3:2 笔记本切到 16:9 外接屏，Dock 尺寸和悬停缩放都保持稳定，不会忽大忽小。

动画自然

Mac 风格最小化飞入、悬停放大、启动弹跳、弧形展开，曲线经过调校，过渡顺滑不闪烁。

功能特性

专注 Dock 本身的完整能力

不做状态栏、不做桌面美化全家桶——只把 Dock 栏该有的功能做完整。

应用与文件夹固定

拖入应用、文件夹、网址即可固定，支持从开始菜单直接拖拽，网页应用可独立窗口打开。

应用组

像 iOS 文件夹一样把图标收进宫格卡片，可命名、可换图标、可调背景与不透明度、可拖拽排序。

弧形堆叠展开

点击文件夹像 macOS 一样弧形列出内部文件，弧度可调（0 为垂直），支持拖出、右键与排序。

时间与日期

时间 / 日期可分别加粗、可调顺序与格式、可显示秒和周几，圆角底盘随深浅色自适应。

速记

点击即记，支持加粗、倾斜、项目符号等基础 Markdown，可导出 txt 与 md，临时保存不丢失。

临时周转组

存放本次工作要用的文件，重启后自动清空，可拖入拖出，做 Dock 上的临时中转站。

起动台

全屏网格列出开始菜单所有应用，打字即搜，回车启动，Esc 关闭，图标懒加载，占用很低。

纯色与渐变背景

纯色、多色渐变、真磨砂玻璃三种背景，可跟随系统强调色，深浅主题自由切换。

运行指示

已打开的应用显示横条或圆点指示，颜色、样式、大小均可自定义，一眼看出谁在运行。

使用指南

几分钟上手

从下载到熟练使用，常用的操作都在这里。

1

下载与启动

  • 从 GitHub Releases 下载 MiniDock.exe
  • 双击运行，无需安装，程序驻留系统托盘
  • 右键托盘图标可打开设置或退出
2

添加应用 / 文件 / 网址

  • 把桌面图标、文件夹、网址直接拖到 Dock
  • 支持从开始菜单拖拽应用图标添加
  • 右键空白处可新建快捷方式 / 应用组 / 网页应用
3

应用组与弧形展开

  • 把一个图标拖到另一个图标上停留，即可合并成应用组
  • 点击应用组，宫格卡片弹出；点「＋」继续添加
  • 点击文件夹图标，以弧形堆叠列出内部文件
4

小组件

  • 设置 → 小组件：开启时间日期、速记、临时组等
  • 速记点击即记，支持 Markdown，可导出 txt / md
  • 临时组用于临时周转，重启后自动清空
5

八页设置

  • 通用：自启动、主题、快捷键、Dock 配置
  • 个性化：Dock 栏 / 图标两套方案，可导入导出
  • 交互动效、图标自定义、小组件、右键菜单、性能、关于
6

快捷键与技巧

  • Ctrl + Alt + D 随时显示 / 隐藏 Dock
  • 右键任意图标：打开、重命名、设置图标、添加分割线
  • 性能页可选「低 / 适中 / 高」三档资源占用预设
协助开发

一起把它做得更好

MiniDock 是完全开源的项目，用纯 C + Win32 + GDI+ 编写，没有任何第三方运行时依赖，也很适合用来学习 Windows 图形编程。欢迎报告问题、提出建议、完善文档或直接提交代码。

  -lcomctl32 -lcomdlg32 -luuid -lurlmon -lversion -ldwmapi ^
  -ladvapi32 -lpsapi -lwbemuuid
