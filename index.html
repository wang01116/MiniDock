Dock：靠近，就会放大

图标按与指针的距离平滑放大，离开后回弹。运行中的应用下方有小圆点，拖拽即可排序。

  • 压缩飞入 / 快照神奇两种最小化动画
  • 分隔线整理工作与娱乐
  • 不透明度 0 时仍可点击
指针靠近时按距离放大

控制中心：一屏开关

网络、蓝牙、深色模式与定位四张卡片；左半点击进入系统设置，右侧箭头打开列表。

  • 音量绑定当前输出设备
  • 内屏不支持硬件调光时自动软件调光
  • 卡片可拖动排序、调整宽度

启动台：找应用不用翻桌面

宫格展示全部应用，支持搜索与网页搜索；图标可以用本地图片或链接替换。

  • 分类标签与分页
  • 搜索引擎 Google / Bing / 百度等
  • 批量图标与深色图标

小组件：信息就在桌面

时钟、通知、资源监视、电池健康与温度，可单独开关，关闭后不再绘制。

  • 电池容量 / 循环次数
  • CPU / 内存 / 磁盘 / 温度

常见问题

你可能想知道的。

为什么不做“液态玻璃”那种复杂动效？
液态玻璃依赖实时模糊、折射与大量图层合成，在低配设备、远程桌面或缩放下容易掉帧，也会显著增加 GPU 与内存占用。MiniDock 选择更轻的渐变、磨砂与放大回弹，优先保证鼠标跟手和长时间稳定。
和 macOS 的 Dock 有多像？
放大曲线、点击回弹、运行小圆点、分隔线、启动台宫格都按 macOS 的使用习惯设计；同时保留 Windows 需要的托盘、任务栏与多显示器逻辑。
为什么免费？如何维护？
MiniDock 由独立开发者利用业余时间维护，MIT 开源，没有会员与付费功能。维护成本主要来自测试与适配，欢迎在 GitHub 提 Issue 或到 B 站反馈。
会收集我的数据吗？
不会。没有账号、遥测或统计脚本；仅在检查更新和下载网页图标时访问网络。详见 条款与隐私。
点击微信 / QQ 图标窗口不能操作？
托盘应用必须由它自己的托盘图标唤醒。MiniDock 会优先点击托盘图标；未登录时直接打开登录页。请确认应用已登录且保留托盘图标。
是否支持 Windows 10？
支持 Windows 10 / 11 64 位。部分新特性（如系统级录屏快捷键）取决于系统版本。
